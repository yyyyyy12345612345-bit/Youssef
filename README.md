## 🌟 أبرز التحديثات في الإصدار 2.5 (v2.5.0)

1. **🔔 نظام إشعارات علوية عائمة أسود ملكي (`AppToast`):**
   - ظهور التنبيهات دائماً أعلى الشاشة تحت شريط الحالة بتصميم أسود داكن (AMOLED Black `#121212`) وأيقونات ملونة وزر إغلاق، مع حماية شريط التنقل السفلي من الحجب.
2. **👤 تخصيص الحساب والصورة الشخصية وتعدد المستخدمين (`UserAvatar`):**
   - إمكانية تغيير اسم المستخدم ورفع صور حقيقية من الكاميرا والاستوديو أو اختيار أفتارات هندسية جاهزة، مع تحديث فوري لكافة الشاشات.
   - حذف حقل "رقم الشعبة" لتبسيط البيانات الأكاديمية.
3. **🚨 محرك إنذارات الاختبارات والكويزات وأذونات الإشعارات:**
   - إنذارات عد تنازلي دورية متكررة لامتحانات الميدتيرم والفاينل (كل 3-5 ساعات في الـ 24 ساعة السابقة للاختبار).
   - منبه خاص للكويزات مع زر تأكيد الاستيقاظ والتركيز **"أنا مستيقظ ومركز"**.
   - فحص وتفعيل كافة أذونات الإشعارات والصوت والشارات تلقائياً فور فتح التنبيهات.
4. **📅 إصلاح وتطوير جدول المحاضرات الأسبوعي:**
   - إمكانية إضافة محاضرات مباشرة مع الإنشاء التلقائي للمقررات غير المسجلة بلون مميز.
   - مزامنة كاملة لأيام الأسبوع من السبت إلى الجمعة مع توافق أيام العطلات الأسبوعية.
5. **📝 بطاقات الملاحظات المدمجة:**
   - عرض مصغر للملاحظات مع خاصية التكبير والتوسيع عند النقر لتوفير مساحة الشاشة.
